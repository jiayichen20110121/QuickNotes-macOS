# 简介：

# QuickNotes 是一个专为 macOS 打造的轻量级悬浮笔记工具，特点是：
	
🪟 悬浮笔记窗口 —— 随时呼出、快速记录

⌨️ 全局快捷键 —— 不管在什么应用都能打开笔记

📄 PDF 导入与预览 —— 支持内嵌查看 PDF

🔍 快速搜索笔记

💾 本地存储，不联网

🎨 界面简洁、无打扰

# 功能特性：

✅ 悬浮窗口

类似微信“微笔记”或 Notion Quick Note，可以一键呼出、查看pdf笔记，无视全屏权限只要点击快捷键即可呼出

✅ PDF 支持
导入 PDF 文件
支持在右侧预览 PDF

✅ 全局快捷键

用户可自定义唤出 / 关闭悬浮笔记的快捷键。

✅ 极简设计
	无复杂界面
	无账号登录
	所有数据本地储存为 纯文本文件
	非常安全私密
